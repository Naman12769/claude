  1. Check and Clean your Hosts File

  The hosts file can force your computer to send github.com to the wrong IP
  address.
  1. Click Start, search for Notepad, right-click it, and select Run as 
     Administrator.
  2. In Notepad, go to File $\rightarrow$ Open and paste this path:

  4. Save the file and close Notepad.

  git push origin main
